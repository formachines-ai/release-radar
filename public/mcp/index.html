MCP server for coding agents

Ask your coding agent what was flagged in a package before it writes code against a new major. A stdio MCP server in one Python file (standard library only) that reads only our public JSON: /today.json and /pkg/<eco>/<name>/index.json. It returns the fields as they are in the JSON — version, date, flag, verbatim quotes, notes link, Errata link — with no model-written text. A flag is a regex match, not a judgement.

Tools

  • releases_today(ecosystem?, stable_only?, limit?) — Releases of the tracked PyPI/npm packages in the site's 7-day window (from /today.json), newest first, with flag, verbatim quotes and links.
  • get_package_releases(ecosystem, name) — What was flagged in one tracked package: its releases in the site's 7-day window with version, date, flag, verbatim quotes, notes link and Errata link (from /pkg/<eco>/<name>/index.json). Regex flag only, no judgement.
  • list_flagged(days?, ecosystem?) — Flagged releases (notes match the breaking/deprecated/removed regex) of the last N days (1-7) across tracked packages, with verbatim quotes and links (from /today.json).
